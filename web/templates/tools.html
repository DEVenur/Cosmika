Custom Tools

Workspace

Give the bot read access to a local directory tree. Files are indexed into the bot's context.

Enable Workspace

Give the bot read access to a local directory

Relative to the bot's working directory, or an absolute path.

Workspace access is read-only (read, list, search). Destructive operations are disabled for safety.

Workspace Context

Auto-generated from files in workspace/ and injected into every conversation. Clear to trigger regeneration on next bot start.

Skills

Drop self-contained skill folders (each with a SKILL.md) into the skills directory. The bot loads them on demand.

Enable Skills

Load skill folders when the bot starts

Relative to the bot's working directory, or an absolute path.

A malformed SKILL.md stops the bot at startup with a clear error, so broken skills are never silently ignored.
